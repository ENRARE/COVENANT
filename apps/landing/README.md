# COVENANT public landing deployment

**MVP:** This package is the isolated, static public landing website. Its only application route is `/`, and its deployable output is `apps/landing/out`.

**MVP:** The package contains presentation-only public values and has no audit fixture, evidence parser, API route, server action, middleware, Netlify Function, RPC capability, Circle integration, wallet, signer, payment command, or financial authority.

**MVP:** The original `apps/web` application remains the local judge-facing product and is not part of this package's deployment artifact.
